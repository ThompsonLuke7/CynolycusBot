## Operations And Bugs

1. **Dealer Ranker entries are far underwater within 13 minutes of filling
   (highest priority).** At the 16:05 ET snapshot, just after the 15:52 orders:
   TEL 1.40 -> 1.40 mark 0.70 (-50.0%), APTV 0.25 -> 0.15 (-40.0%), FIG 0.80 ->
   0.56 (-30.0%), U 0.71 -> 0.51 (-28.2%), VIAV 1.65 -> 1.40 (-15.2%), LITE
   8.50 -> 7.70 (-9.4%), HPE 0.92 -> 0.92 (0.0%). Median about -28%. A move that
   large in 13 minutes is spread crossing, not price action. The consequence is
   direct: the -50% stop is evaluated on the next run, so a position can be
   stopped out purely on its own entry slippage. Both dealer stops today (TRMB
   -$2,835 and NTNX -$2,600) had `runs_held=1` — stopped at the first evaluation
   after entry. Per `AGENTS.md`, verify the mark source (bid vs mid vs last
   print) and the fill price against the quoted spread before drawing any
   conclusion about dealer signal quality from this P&L.
2. **Trim/partial exits do not decrement the managed position size.** In
   [core/live_4h_exec.py:325-330](core/live_4h_exec.py#L325-L330) the `trim`
   branch appends a partial sell and sets `st["trimmed"] = True` but never
   reduces `st["contracts"]` / `st["shares"]`. Trading is unaffected — the exit
   quantity is re-read from the broker each run at
   [core/live_4h_exec.py:261](core/live_4h_exec.py#L261) — but any open-book
   valuation computed from state is overstated. Confirmed against the broker:
   dealer FIG state says 61 contracts, broker holds 31; dealer P state says 11,
   broker holds 5.
3. **One order error, AZN.** At 09:35:41 the swing market-close fallback failed
   HTTP 403 `no available quote for symbol. please reenter with a limit` on
   AZN260918C00165000. The retry ladder recovered and the position closed at
   09:40:13 at 2.80. Not stuck, but the fallback path assumes a marketable
   quote exists and has no limit-order fallback of its own.
4. **Six unverified swing buys were correctly skipped** from local opens
   (HUBB, LOGI, BHP and three others; `status=new via=timeout`). Behaviour is
   right — no phantom local position — but the orders were still submitted, so
   these can surface later as broker positions the swing module does not own.
5. **Four `not_found` drops from managed state**: DELL (HTF, submitted in the
   09:37 pre-open flush, never filled, dropped 14:25), and UMC / GRAB / TSCO
   from dealer at 15:52. The pre-open flush writes an entry into managed state
   on submission, so an unfilled limit order lingers as a phantom managed
   position for roughly five hours until the next run reconciles it.
6. **Pre-existing, not from today:** `Data/inference/dealer_ranker/closed_trades.jsonl`
   contains an `audit_gap` record from an unclean host shutdown on 2026-08-04
   (748 NUL bytes, roughly 2 lost records). Noted so it is not mistaken for a
   new corruption event.
7. No stream pressure. Swing accepted 209,481 of 209,481 raw bars, zero drops.
   One isolated HTTP 429 on a quote fetch occurred on 8/13, not today.
