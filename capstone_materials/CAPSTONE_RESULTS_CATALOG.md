# Capstone Results Catalog

## Interpretation rules

- **R**: reproduced/asserted in this audit's bounded tests.
- **L**: locked primary artifact; previously generated by reproducibility code, not recomputed now if slow.
- **S**: stored historical result inspected but not rerun.
- **D**: documented/anecdotal observation.
- **U**: unverified or contradicted; do not cite as a result.

Financial metrics are not interchangeable. “Frozen test” means policy chosen on validation then run once on test. “WF-OOF” means chronological out-of-fold predictions with a 21-day embargo, but model family/seed selection was not nested. Most event-driven strategy results use fixed $1,000 notional per signal, a $100,000 display base, unconstrained concurrent positions and exit-time P&L booking; they are not compounded account returns.
