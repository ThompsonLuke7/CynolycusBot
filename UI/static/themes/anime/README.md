# Anime theme images

Drop your own image files here to customize the **Anime** theme (selectable
from the **Themes** tab in any dashboard's top nav):

- `bg.jpg`    — full-page background (shown dimmed behind the UI)
- `corner.png` — corner art (bottom-right, transparent PNG works best)

Nothing ships here by default. The app only displays files you place in this
folder; if a file is absent, that slot simply shows nothing. These images are
served read-only at `/static/themes/anime/<file>` by every dashboard.
